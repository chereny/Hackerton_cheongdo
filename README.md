# 청도 디지털 생활도우미

스마트폰 사용이 익숙하지 않은 어르신이 생활 과제를 한 단계씩 연습하고, 어려운 점은 동네 모임에 질문하는 반응형 웹 데모입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 출력한 주소를 여세요. 프로덕션 빌드는 `npm run build`로 생성합니다.

## 데모 범위

- 사진 보내기, 버스 정보 찾기, 길 찾기, 글자 크게 보기 과제
- 브라우저에 저장되는 학습 진행, 완료 표시, 개인 배지
- 준비된 안내 예시를 사용하는 코치 체험 화면과 근거 자료 표시
- 브라우저 저장소 기반 모임 질문·도움 요청, 답변, 해결, 신고, 운영자 숨김 시연
- 체험용 집계, 글자 크기 조절, 브라우저 음성 읽기

데모 기록은 현재 브라우저의 `localStorage`에만 저장되며 다른 기기와 공유되지 않습니다. 모임 글은 같은 브라우저 안에서만 보이고, 실사용자·운영 데이터와 연결되지 않습니다. 코치 화면은 예시 답변을 보여주는 UI 데모이며 GitHub Copilot SDK, Microsoft Agent Framework, 서버 API, Azure 서비스에는 연결되어 있지 않습니다. 실제 AI·다중 사용자·영속 저장·클라우드 배포는 관련 런타임과 자격 증명 및 Azure 환경을 검증한 뒤 별도 구현해야 합니다.

제품 요구사항과 기술 설계의 기준 문서는 [`docs/PRD.md`](docs/PRD.md), [`docs/TRD.md`](docs/TRD.md)입니다.
